🚀 落地通關與 JR Pass 兌換步驟

1. 日本入境 Visit Japan Web 申報

請於出發前 48 小時填寫完畢，並將產出的 QR Code 截圖存於手機。

2. 機場落地更換 JR Pass 與劃位 (Step-by-step)

黑色的指定席自動售票機操作指引：

  1. 抵達 B1 車站：下飛機後跟著「JR 鐵路 (Train)」指標走到地下 1 樓。
  2. 尋找機器：找到掛有「護照讀取機」的黑色自動售票機（免去窗口排隊）。
  3. 掃描取票：螢幕選繁體中文 ➔「更換 e-ticket / 取票」➔ 掃描手機 QR Code ➔ 依序放入護照驗證 ➔ 印出實體周遊券。
  4. 免費劃位：點選「使用優惠車票預訂指定席」 ➔ 插入周遊券 ➔ 預訂「札幌 ➔ 旭川」與「旭川 ➔ 札幌」的特急列車指定席座位。

📅 每日詳細行程規劃

🟢 7/21 (二) Day 1：落地直奔北國大地，入住美瑛緩慢

今日路線：新千歲機場 ➔ 札幌 ➔ 旭川 ➔ 美瑛 ➔ 緩慢北海道

交通 Step-by-step 指引：

  1. 使用 JR Pass 搭乘「快速 AirPort 號」至札幌站（37 分鐘）。
  2. 轉乘特急列車 Lilac 或 Kamui 號至旭川站（1 小時 25 分鐘，對號入座）。
  3. 轉乘「JR 富良野線」普通電車到美瑛站（34 分鐘，全車自由席）。
  4. 抵達美瑛站後，搭乘計程車或利用民宿 16:30 / 17:30 的接駁服務。

活動點評：傍晚在緩慢民宿周邊散步，享受森林環繞的寂靜，放鬆洗滌搭機的疲憊，享用著名的緩慢晚餐。

🟢 7/22 (三) Day 2：美遊巴士深度遊（青池、白鬚瀑布、四季彩之丘）

今日路線：美瑛站 ➔ 參加 Biei View Bus（美遊巴士） ➔ 美瑛名樹群（拼布之路）

交通 Step-by-step 指引：

  1. 早上由民宿接駁或搭車至「JR 美瑛站」。
  2. 步行 1 分鐘至美瑛町觀光協會（四季の情報館）巴士櫃檯出示預約 QR Code 報到上車。

景點重點：

  • 白金青池：枯木與鈷藍色水面交織的夢幻奇景。
  • 白鬚瀑布：從岩縫湧出、直瀉入美瑛川的震撼景致。
  • 四季彩之丘：大片彩色花毯與遠方山脈交織的震撼大自然。
  • 空檔加碼：在美瑛車站前租借腳踏車（建議選電動輔助型），騎乘「拼布之路」看肯與瑪麗之樹、七星之樹。

🟢 7/23 (四) Day 3：慢車號浪漫薰衣草（富田農場）

今日路線：美瑛 ➔ 薰衣草花田站 ➔ 富田農場 ➔ 富良野 / 旭川 ➔ 美瑛緩慢

交通 Step-by-step 指引：

  1. 從美瑛站搭乘夏季限定的「富良野・美瑛慢車號 (Norokko 號)」（持 JR Pass 可免費搭乘）。
  2. 在臨時站「薰衣草花田站（ラベンダー畑駅）」下車，步行 7 分鐘即達富田農場。

活動點評：7 月下旬正是薰衣草全盛期！必吃薰衣草冰淇淋、哈密瓜。下午若有空檔，可續搭火車前往「富良野站」或往北去「旭川站」吃碗正宗旭川拉麵，晚上回美瑛緩慢。

🟢 7/24 (五) Day 4：告別丘陵，前進札幌市區

今日路線：美瑛 ➔ 旭川 ➔ 札幌 ➔ Vessel Inn 札幌中島公園

交通 Step-by-step 指引：

  1. 從美瑛搭普通電車回旭川站。
  2. 在旭川站持 JR Pass 及指定席車票，搭乘特急列車直達札幌站（Pass 最後一天有效）。
  3. 抵達札幌站後，轉乘札幌市營地下鐵南北線（此段自費 210 日圓），搭到「中島公園站」，出站步行 1 分鐘即達 Vessel Inn 飯店。

活動點評：下午可逛大通公園、札幌電視塔、狸小路商店街補貨購物，晚上吃成吉思汗烤羊肉或札幌著名的湯咖哩。

🟢 7/25 (六) Day 5：海鮮丼吃到飽，心滿意足回台灣

今日路線：飯店 ➔ 札幌站 ➔ 新千歲機場 ➔ ✈️ 溫暖的家

交通 Step-by-step 指引：

  1. 早上在飯店享用全日本排名名列前茅的「Vessel Inn 百匯海鮮丼早餐」（鮭魚卵、甜蝦干貝無限裝）。
  2. 搭地下鐵南北線回札幌站（自費 210 日圓）。
  3. 在札幌站自動售票機購買「快速 AirPort 號」單程票（自由席 1,430 日圓），搭至新千歲機場車站。

貼心提醒：提早 3 小時到新千歲機場，國內線航廈有極其好逛的小樽洋菓子舖 LeTAO、Royce' 巧克力工廠，做最後的土產採購後登機。

⚠️ 備註：清單中的「函館」單程車程超過 4.5 小時，已標註為「建議下次再訪」，本次不予列入以確保行程不疲奔波。

🗣️ 日語情境溝通範例 (指手便攜包)

遇到情況時，可以直接出示下方繁體中文及日文畫面給工作人員看：

情境一：在車站更換 JR Pass 或尋求協助

不好意思，我想兌換 JR Pass。

すみません、JRパスの引き換えをしたいです。

羅馬拼音：Su-mi-ma-sen, jē-ā-ru-pa-su no hi-ki-ka-e o shi-tai de-su.

情境二：在美瑛車站前租借腳踏車

我想租兩台電動輔助腳踏車，租到下午四點。

電動アシスト自転車を2台、午後4時まで借りたいです。

羅馬拼音：Den-dō a-shi-su-to ji-ten-sha o ni-dai, go-go yo-ji ma-de ka-ri-tai de-su.

情境三：在飯店辦理入住 Check-in

你好，我有預約，名字是 [你的英文護照名]。這是我們的護照。

こんにちは、予約しています、名前は [英文名] です。これは私たちのパスポートです。

羅馬拼音：Kon-ni-chi-wa, yo-ya-ku shi-te i-ma-su, na-mae wa [英文名] de-su. Ko-re wa wa-ta-shi-ta-chi no pa-su-pō-to de-su.
